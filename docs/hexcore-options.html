#38 — the hex core does not reach the flats

A hexagon inscribed in a circle falls short by 1 − cos 30° = 13.4% of the radius, in six places. This page draws the same lattice the wheel uses — pointy-top cells, centres √3·s apart along a row and 1.5·s between rows, kept by hex-ring distance — at the three treatments, so the choice is visual rather than arithmetic. Same cell size in all three; only the boundary differs.
